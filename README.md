# MLB Real-Time Game Tracker (Mobile-First Web App)

MLB（メジャーリーグベースボール）の特定1試合をリアルタイムで追跡できる、スマートフォン最適化済みの高密度ライブトラッカーWebアプリケーションです。

---

## 🌟 主な特徴 & 実装機能

### 1. お気に入り球団設定 & 自動試合ローディング
- **デフォルト球団**: ロサンゼルス・ドジャース (LAD / teamId: 119)
- **LocalStorage 永続化**: 全30球団からお気に入り球団をいつでも変更・保存可能
- **自動検出**: 起動時に当日のMLB全スケジュールからお気に入り球団の試合を自動判定して最優先表示
- **試合状態別ビュー**:
  - **試合前 (Preview)**: 開始予定時刻、対戦カード、両軍の予告先発投手
  - **進行中 (Live)**: 5秒おきの自動高速ポーリングで配球や走者をリアルタイム追跡
  - **試合終了 (Final)**: 最終スコア、勝敗/セーブ投手、ラインスコア

### 2. スコアボード & ダイヤモンド走者
- **スコア & ラインスコア**: イニング別の得点一覧、安打数 (H)、失策数 (E)
- **得点圏アラート (RISP)**: 走者が2塁または3塁にいる場合、ダイヤモンドがゴールドパルス発光
- **塁上の走者名表示**: 1塁・2塁・3塁に誰が出塁しているかを明記
- **BSO カウントランプ**: ボール(緑)、ストライク(黄)、アウト(赤)のLEDインジケーター

### 3. ピッチトラッカー & ストライクゾーン (SVG)
- **対決カード**: 投手（投球数、防御率） vs 打者（打率、打席・成績、顔写真）
- **Statcast 座標プロット**: ストライクゾーン（3×3グリッド）内に球種、球速（mph/km/h併記）、コース、投球順番号をプロット
- **判定色分け**: ボール(緑)、見逃し(赤)、空振り(紫)、ファウル(黄)、インプレー(青)
- **最新投球パルス**: 最新球のアニメーションリング表示

### 4. 実況フィード & 簡易日本語ステータス変換
- 最新プレーが先頭に来るリアルタイムタイムライン
- 英語の公式 description を解析し、主要イベントを分かりやすい日本語ラベルに変換して先頭に付与:
  - `[本塁打]` 大谷翔平: 右中間への第○号ソロホームラン！ (430 ft / 112 mph)
  - `[適時打]` ベッツ: レフト前タイムリーヒット！
  - `[空振り三振]` 山本由伸: 空振り三振に仕留める！
- Statcast 打球初速、打球角度、飛距離バッジ表示
- 「得点シーンのみ」のワンタップフィルター

### 5. エキサイト演出 & モバイル触覚フィードバック
- **ホームラン演出**:
  - `canvas-confetti` による全画面ダイナミック紙吹雪
  - ゴールドネオンに輝く「HOMERUN!」特大バナー
  - スマホのバイブレーション（`navigator.vibrate([100, 50, 100, 50, 200])`）
- **Statcast ハードヒット警戒アラート**:
  - 打球初速が **100.0 mph 以上** の場合、燃える炎アイコンと赤色パルスバッジ（`🔥 108.5 MPH HARD HIT`）を即座にポップアップ
- **テストボタン完備**: ヘッダー上の「HR演出」「100mph」ボタンでいつでも手動テスト可能

### 6. 厳選名勝負ハイライト & ライブシミュレーター
- オフシーズンや試合がない時間帯でもすぐに動作確認できるよう、伝説の名勝負をプリセット収録:
  - 大谷翔平「50-50」達成試合 (2024-09-19 vs マーリンズ 6安打3本塁打10打点2盗塁)
  - 2024 ワールドシリーズ第1戦 (2024-10-25 フリーマン逆転サヨナラ満塁弾)
  - 2024 NLDS第5戦 (2024-10-11 山本由伸 vs ダルビッシュ有)
- **ライブ再現シミュレーター**: 1打席ずつ進めたり、自動再生でリアルタイムの試合進行を追体験可能

## 🛠 技術スタック
- **Frontend**: Vite, React 19, TypeScript
- **Styling**: Tailwind CSS
- **State / Data**: TanStack Query (v5), LocalStorage
- **FX / Feedback**: canvas-confetti, Web Vibration API
- **Icons**: Lucide React
- **Data Source**: MLB Stats API (公式 REST API, 認証不要)

## 🚀 起動方法

```bash
# プロジェクトディレクトリに移動
cd C:\Users\cerve\.gemini\antigravity\scratch\mlb-tracker

# 依存パッケージのインストール（初回のみ）
npm install

# 開発サーバー起動
npm run dev
```

起動後、ブラウザで [http://localhost:5173/](http://localhost:5173/) にアクセスしてください。
同一Wi-Fi環境のスマートフォンからは、ターミナルに表示される Network URL（例: `http://192.168.x.x:5173/`）にアクセスすることで、スマホでの触覚フィードバック（バイブレーション）やタッチ操作を直接体験できます。
